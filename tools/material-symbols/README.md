# Material Symbols

Icons for `tools/logo.py --icon <name>`, which turns one into a white logo with a name beside it, for system apps
that have no wordmark (Media Player, Play Store, Settings, TV, Weather).

- Source: [google/material-design-icons](https://github.com/google/material-design-icons), commit
  `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`, `symbols/web/<name>/materialsymbolsrounded/<name>_fill1_24px.svg`
  (Rounded, filled, weight 400, 24 px).
- Licence: Apache License 2.0, in [LICENSE](LICENSE). Copyright Google LLC. The files are unchanged.

To add another icon, take the same style from the same folder of that repository, find it by name on
https://fonts.google.com/icons, and save it here as `<name>.svg`.

| File | Used for |
|---|---|
| `play_circle.svg` | Media Player |
| `shop.svg` | Play Store |
| `settings.svg` | Settings |
| `live_tv.svg` | TV |
| `partly_cloudy_day.svg` | Weather |
