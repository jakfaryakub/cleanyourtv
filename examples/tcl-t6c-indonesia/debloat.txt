# Known on this unit:
# - The saved Wi-Fi network belongs to android.uid.system, so setupwraith can go without dropping Wi-Fi.
# - com.tcl.ttvs hosts the firmware updater (versionUpdateApp SystemUpdateReceiver/UpdateEntranceActivity)
#   and T-Cast, besides TCL analytics (TrackDataService, UsagestService, BIService) and the Samba video
#   service. Kept here for firmware updates.
# - A second Android user (id 10) exists; the list only touches user 0.
# - The Samba opt-out is not reachable here: Settings > Privacy has no Samba entry (its settings
#   activities are not exported, and TvSettings shows no Samba slice on this firmware). With
#   tv.samba.ssm.ui disabled and ttvs kept, Samba stayed disabled and no Samba service ran after a reboot.
# - Same key-repeat trade as docs/devices/tcl-55p71b-g09-key-repeat.md: with InputKeyService and
#   HomeKeyService bound (capabilities=8), holding Vol+/Vol- moves one step per press; without them it
#   ramps. "consume_volume_keys": true from a theme (key_filter true) did not bring the ramp back.
#   Kept both helpers for the remote buttons and lives with one step per press.
# - Launcher handover: install with STOCK_LAUNCHER=none first, then disable setupwraith, then launcherx,
#   then set-home-activity (mFocusedApp confirmed the new launcher), then dreamx after
#   screensaver_components was set to com.gathin.tvhome/.ClockDream. APP_AUTO_START needed (the
#   install script sets it with appops write-settings).
